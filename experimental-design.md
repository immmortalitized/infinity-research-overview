# Conceptual experimental design

INF-EXP-0001 is planned as a controlled comparison of memory representations for long-horizon evidence tracking and belief revision. The project remains in engineering and methodological validation; the descriptions below are conceptual roles, not completed validation.

## Planned comparison conditions

| Condition | Conceptual role |
| --- | --- |
| Stateless | A baseline without persistent memory across steps. |
| Chronological prose memory | A persistent narrative record organized over time. |
| Structured epistemic state | A persistent explicit representation of evidence and belief state, evaluated as a bundled treatment. |
| Matched prose reasoning | A prose comparator intended to account for reasoning support without the same structured-state representation. |
| Deterministic ledger | A comparator using a consistently maintained record to examine the value of bookkeeping. |
| Full history | A comparator retaining the prior interaction history to examine the value of access to earlier context. |

These roles do not imply that the conditions are already fair or validated. Comparator fairness is a gate to testing.

## Planned methodological safeguards

- Establish evaluator isolation before real-model testing.
- Review comparator fairness and strong controls before interpreting differences.
- Version the methodology so the basis of any future result can be traced.
- Deliberately seek failure cases and alternative explanations.
- Treat negative and inconclusive outcomes as valid results.

These safeguards are plans and requirements. This document does not claim that they have passed validation.

## Interpretation

The intended study concerns the tested bundled structured-state treatment. A future positive result would not establish adaptive orchestration, substrate independence, self-improvement, or the broader Infinity thesis.

This public description omits implementation, benchmark construction, prompts, evaluator internals, data, exact scoring, and private assets.
