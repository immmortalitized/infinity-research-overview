# Infinity: research overview

**Can persistent structured epistemic state improve long-horizon evidence tracking and belief revision relative to strong alternative memory representations under controlled conditions?**

Infinity is an independent undergraduate research project led by Zahir Haynes-Sharif. This repository presents the research question, conceptual comparison, current status, and planned methodological gates.

The project remains in engineering and methodological validation. No empirical H2 claim has been made. Real-model testing is intentionally blocked until evaluator isolation, comparator fairness, and methodological gates are satisfied; this overview does not claim those gates have passed.

## Research scope

INF-EXP-0001 is a planned controlled comparison of memory representations. The conceptual conditions are stateless, chronological prose memory, structured epistemic state, matched prose reasoning, deterministic ledger, and full history. Their roles are described in the [experimental design](experimental-design.md).

A future positive result would apply only to the tested bundled structured-state treatment. It would not establish adaptive orchestration, substrate independence, self-improvement, or the broader Infinity thesis.

## Research approach

Negative results are valid outcomes. Strong controls, comparator fairness, versioned methodology, and deliberate attempts to falsify the hypothesis are central to the planned work. Planned validation is distinguished from completed evidence throughout these documents.

This overview is conceptual. It contains no experiment implementation, benchmark construction, prompts, evaluator internals, unpublished data, or private experiment assets.
